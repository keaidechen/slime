## 2. 本轮明确纠正的几处混淆

- **EP 与总卡数。** 当前 Megatron 在 `parallel_state.py` 分别构建普通参数和 expert 的 rank generator；不能把所有缩写无条件相乘。详见[源码问题](../docs/megatron_code_walkthrough/06_reference/03_source_questions.md)。
- **优化器顺序。** `DistributedOptimizer.step_with_ready_grads` 先执行本地更新，再触发或安排参数同步，参数 AllGather 可与后续执行重叠。原摘要中“先 all-gather 再各自更新”的概括已撤下，统一读[优化器主章](../docs/megatron_code_walkthrough/03_state_and_memory/01_data_parallel_optimizer_checkpoint.md)。
- **StatelessAdam。** 重置矩估计改变更新规则，不能只描述为等价的显存优化；统一读[slime 后端中的数学说明](../docs/code_walkthrough/06_megatron_backend_and_mbridge.md)。
- **换权事务。** abort、pause、update 出现在同一接口链中不等于跨 rank 原子发布、自动回滚或失败后仍一致。统一读[SGLang 控制面](../docs/sglang_code_walkthrough/04_interfaces_and_models/03_control_plane_and_post_training.md)。
- **回放与 on-policy。** 返回 logprob、top-p 或路由信息有助于对齐，但不应称为“完整随机性上下文”并直接推导严格 on-policy，见[数值正确性基础](00_Foundations/08_RL数据与数值正确性.md)。
- **性能案例。** GPU 空闲案例中的节点和吞吐明确标为教学构造；不是已执行的 H20 测量。

## 3. 新课程的接口依据

新增示例采用小范围接口，并注明执行条件。接口依据与解释来自一手文档：

- [PyTorch CUDA notes](https://docs.pytorch.org/docs/stable/notes/cuda.html)：异步执行与缓存分配器。
- [PyTorch Tensor Views](https://docs.pytorch.org/docs/stable/tensor_view.html)：view/storage 与布局。
- [PyTorch Distributed](https://docs.pytorch.org/docs/stable/distributed.html)、[torchrun](https://docs.pytorch.org/docs/stable/elastic/run.html)：进程组与两进程启动。
- [Ray Actors](https://docs.ray.io/en/latest/ray-core/actors.html)、[ray.wait](https://docs.ray.io/en/latest/ray-core/api/doc/ray.wait.html)：有状态 worker 与就绪结果。
- [Triton Vector Addition](https://triton-lang.org/main/getting-started/tutorials/01-vector-add.html)：program、索引、mask 与参考验证。

这些链接会更新。运行前记录本机版本；主线不要求安装某个“最新”版本。原模型与硬件长文中的日期、产品、API 和性能报告保留为原资料，未在本轮全部重新事实核验，不能将页面自述的“核对日期”当作本轮验证结论。

复查文档结构可运行：

```bash
python tools/validate_learning_docs.py
python learn_docs/labs/loss_normalization.py
```

两条命令都可从仓库根目录执行：

- `validate_learning_docs.py` 检查本地 Markdown 链接、锚点、代码围栏、迁移记录和教学脚本语法。输出中 `error_count` 应为 `0`；非 0 时，后续各行会列出错误类型和文件。加 `--json` 可得到适合程序处理的 JSON 输出。
- `loss_normalization.py` 运行一个纯 Python 的 loss/梯度缩放算例。正常时打印包含 `mean_of_means`、`global_mean`、`reference_gradient` 和 `DDP_average_of_scaled_gradients` 的字典；最后两个梯度值应相等。

正常打印结果不代表“所有文档里的 GPU 实验都通过”。这两条命令都不运行 PyTorch GPU、Ray、Triton 或多机通信实验。

验证器不启动 GPU/集群，不验证所有外链可达性，也不执行旧文档中的伪代码。实际性能结论必须有环境、workload、重复测量、原始结果和正确性证据。
