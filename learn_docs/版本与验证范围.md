## 验证方式与限制

`python tools/validate_learning_docs.py` 检查本地 Markdown 路径、锚点、围栏、历史迁移记录、当前百科登记和独立教学脚本语法。检查范围包含百科与关联源码、论文、性能文档。

`python learn_docs/labs/loss_normalization.py` 是纯 Python 数值算例。新增文档中的容量、矩阵乘、分页和成本算例还进行了独立算术核对。

这些检查不执行 GPU、多机通信、Ray、Triton 或完整框架实验，不验证全部外链，也不证明硬件性能或模型质量。当前文档中的实测资格没有因为本轮整理而改变；没有新写入 GPU 实测结果。

写作和引用规则见[证据约定](写作与证据约定.md)。
