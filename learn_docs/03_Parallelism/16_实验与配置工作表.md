## G. 逐级实验

1. 单 GPU operator baseline；
2. 单 parallel dimension：只 TP、只 FSDP、只 CP 等；
3. 两维组合，验证 layout transition；
4. 单节点完整配置；
5. 两节点验证 network boundary；
6. 中等规模观察 algorithm/topology 切换；
7. 全规模测 scaling、tail 和 fault recovery；
8. 真实数据长度/token routing distribution，而非只用固定 synthetic batch。

## H. Correctness 检查

- 固定 seed，对比单卡/分布式 loss 与 gradient；
- 验证 DP token-weighted loss normalization；
- TP/CP/EP 重排前后 token index、mask、position 一致；
- tied weight 在 PP 首尾只更新一次且同步正确；
- FSDP/TP checkpoint 可换 parallel degree load；
- RL policy version、log probability 与 rollout 对齐；
- 多 rank overflow/gradient clipping 使用正确 group。

## J. 常见故障定位

| 现象 | 优先假设 |
|---|---|
| 增 TP 反而慢 | GEMM 变小、collective latency、跨节点 |
| PP bubble 高 | micro-batch 少、stage imbalance、P2P exposed |
| CP 长短样本差异大 | 固定 degree、causal imbalance、packing metadata |
| EP p99 抖动 | router hot spot、AllToAllV、expert GEMM imbalance |
| FSDP OOM | prefetch/full-param peak、wrapping、workspace |
| loss 随 world size 变 | reduction group 或 normalization 错误 |
| hang | group membership、collective order、uneven steps、rank failure |
