## 历史与当前记录

- [上一轮迁移记录](reference/2026-09-06迁移记录.md)保留历史背景，不代表当前课程和文档数量。
- `document_manifest.json` 保留原始来源身份与当前去向，`document_routes.json` 记录历次删除或移动路径及章节去向。
- `encyclopedia_catalog.json` 登记当前百科全部 Markdown，包含领域、类型、术语别名与相关条目；它与历史来源登记分开维护。
- `document_expansions.json` 保留上一轮算例扩写的来源记录，并更新到当前路径。

没有为每个旧路径复制跳转正文。仓库外旧书签可以按本表及机器可读记录查找；原有显式章节锚点和被引用的标题锚点尽量保留。
