## 如何核对

先独立算出各表，再运行对应的标准库脚本。程序中的矩阵参考、有限差分和状态模型用于发现手算错误，不模拟真实分布式后端。

```bash
python3 learn_docs/labs/parallel_runtime_walkthroughs.py
python3 learn_docs/labs/training_rl_walkthroughs.py
python3 learn_docs/labs/loss_normalization.py
```

[并行与运行时脚本](labs/parallel_runtime_walkthroughs.py)覆盖DDP目标与bucket、分片更新、TP矩阵与梯度、PP依赖与峰值、CP softmax/梯度、EP原序合并、通信组以及KV页表和调度状态。

[训练与RL脚本](labs/training_rl_walkthroughs.py)覆盖AdamW算术、packing分母、教学checkpoint提交条件、KV容量、PD时间、推测概率校正、PPO梯度、GAE和队列准入。状态机检查只验证声明的教学协议，不能证明仓库具备相同的故障恢复实现。

要解释这些方法为何出现，进入[训练并行史](08_Parallelism/训练并行演进史.md)、[推理运行时史](10_Inference_Serving/推理运行时演进史.md)和[RL系统史](11_RL_Systems/RL系统演进史.md)。代码映射和实测边界见[版本与验证范围](版本与验证范围.md)。
