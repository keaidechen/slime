# 张量、形状、布局与复杂度

> 类型：基础概念。前置：[数字编码](../00_Physical_Foundations/信息与数字电路.md)。

## 数学对象与物理对象

数学张量描述多维元素；程序中的 tensor 还携带 dtype、shape、stride、device、storage offset 等信息。同样的数值和形状可以有不同存储布局，也可以与另一个 tensor 共享底层存储。

对形状 [2,3]、stride [3,1] 的连续张量，元素 $(i,j)$ 的存储偏移为 $3i+j$。转置后形状 [3,2]、stride [1,3]，可以只改元数据。若下游只能高效消费另一种布局，则成本出现在消费者或显式复制处。

## 矩阵乘与广播

$X_{M\times K}W_{K\times N}=Y_{M\times N}$ 表示沿 K 求和。M、N 决定输出空间，K 是规约维。Batched GEMM 增加 batch 维，不等于把互不相关的所有维度混成一次任意 reshape。

广播让尺寸为 1 的维度按逻辑重复，不保证物理复制。反向传播时，广播维上的梯度需要求和回原形状。例如 $Y_{ij}=X_{ij}+b_j$，则 $\partial L/\partial b_j=\sum_i\partial L/\partial Y_{ij}$。

## 复杂度不是完整成本

时间复杂度描述规模增长趋势，需要声明自变量。Attention 的 $O(S^2)$ 通常指序列长度 S 的某部分计算；模型 hidden size、head 数和 batch 都不能凭空消失。

空间也要区分输入输出、常驻状态、临时工作区和峰值活跃集合。中间矩阵不被物化，可能降低内存占用，但并不必然改变数学运算数量级。

对 GEMM，常见 FLOP 口径约 $2MKN$；存储字节由元素数乘每元素字节得到。通信量则取决于分片与规约，不能从 FLOP 数直接推出。

## 小例子：相同 token 数，不同 Attention 工作量

两条长度 512 的独立序列共有 1024 token，密集注意力可见矩阵总大小与 $2\times512^2$ 同阶。一条长度 1024 的序列对应 $1024^2$，两者不同。Packing 若保留序列边界，不能让不同样本互相注意。

因此配置表应同时记录序列长度分布、mask、布局和 batch。用一个平均长度替代整个分布可能低估计算和峰值内存。

## 从手写索引到布局抽象

连续数组简化地址计算；view 避免复制，但引入别名和非连续布局；分布式 tensor 进一步描述元素归属，却需要在算子边界处理重分布。抽象提升后，物理流量仍需单独核算。
