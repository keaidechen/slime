# 信息与数字电路：从物理状态到 bit

> 类型：基础概念。适用范围：数字系统的共同抽象；电路图景为简化模型，不能代替具体芯片电气规格。

## 信息需要物理载体

bit 是两种可区分逻辑状态的选择。实际器件通过电压区间、电荷、磁化方向等物理状态承载它。逻辑 0 和 1 并不要求处处使用相同电压；接收电路依照约定的阈值解释信号。物理值连续变化，数字接口则只承认有限的合法区间。

这层抽象允许我们把一个复杂电路看成布尔函数，但前提是输入电平、传播时间和供电等条件得到满足。噪声裕量使小扰动不必改变逻辑值；超出范围后可能误判，而不是自动得到一个“稍微不准确的 bit”。

八个 bit 可以表示 256 种组合。它们解释为无符号整数、有符号整数、字符还是浮点数，由编码决定。相同字节不能脱离 dtype 和协议解释；网络收到 BF16 的位模式后，按 FP16 解码不等价于数值类型转换。

## 晶体管、逻辑门与状态

在数字电路的开关模型中，晶体管用控制端调节导通。多个器件组成反相、与、或等逻辑，再组成加法、比较、选择等功能。CMOS 利用互补器件实现逻辑；真实功耗包括切换活动和漏电等部分，不能把“静态没有理想直流通路”理解成完全不耗电。

组合逻辑的输出由当前输入决定，但信号需要时间传播。时序逻辑加入保存状态的元件，输出还取决于过去。寄存器保存一次操作的结果，随后成为下一次操作的输入。程序循环最终对应反复更新硬件状态，而不是一份数学表达式凭空瞬间完成。

```mermaid

    A[物理信号] --> B[逻辑电平与编码]
    B --> C[组合逻辑：加法和选择]
    C --> D[寄存器：保存结果]
    D --> C
    D --> E[指令与程序状态]
```

## 时间也是接口的一部分

同步电路以时钟边沿协调状态更新。组合路径要在下一次采样前稳定，并满足寄存器的建立与保持要求。提高频率会压缩可用时间；把一条长路径分成更多流水级能缩短每级工作，却增加寄存器、控制和依赖处理成本。

跨时钟域的信号不能假设在接收方时钟边沿附近稳定。同步器、握手和异步 FIFO 分别处理特定场景；它们不能由软件里的一个 `await` 替代。软件同步建立在底层已经实现的时序与可见性契约之上。

## 从单位看成本

| 量 | 含义 | 常见混淆 |
|---|---|---|
| bit / byte | 编码位与 8 位字节 | Gb/s 直接当成 GB/s |
| Hz | 每秒周期数 | 当作每秒指令数或 FLOP 数 |
| J | 能量 | 与瞬时功率混为一谈 |
| W | 每秒消耗的能量 | TDP 当作每次运行的固定功率 |
| ns / μs / ms | 时间 | 混用数量级后仍比较性能 |

示意：一条理想 32 Gb/s 链路的原始位速率对应 4 GB/s。协议与编码可能进一步占用带宽；也不能由这个数字得知一次小消息的完整往返延迟。

## 问题、方法与新约束

| 问题 | 方法 | 新约束 |
|---|---|---|
| 物理信号受扰动 | 数字电平、噪声裕量、再生 | 阈值、时序和功耗约束 |
| 大功能难以整体设计 | 逻辑门、模块、指令等抽象 | 抽象隐藏了物理延迟和资源共享 |
| 长逻辑路径限制频率 | 流水线 | 相关操作等待、分支恢复、额外状态 |
| 错误无法完全避免 | 检测、纠错、重试 | 冗余位、延迟和可覆盖错误范围 |

这些是设计问题的层次，不表示所有技术按表中顺序出现。软件中的类型正确和硬件中的位传输可靠也是两件不同的事。
