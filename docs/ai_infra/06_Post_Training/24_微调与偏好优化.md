## 1. 从预训练到微调与在线 RL：目标、参数和执行阶段

> 前置：[训练更新](<../04_Training/12_数据管线与训练循环.md#s1>)、[Packing 与 mask](<../04_Training/12_数据管线与训练循环.md#s2-packing的目标边界与有效分母>)。本文比较系统职责；具体算法的归约和正则项须另行声明。

<a id="s1-数据目标与参数更新是两条轴"></a>

### 数据目标与参数更新是两条轴

预训练学到的是“语料中什么 token 常跟在什么上下文后面”，并没有直接规定如何遵守某种回答格式、如何比较两个解法，或如何利用一次测试失败。后训练在已有模型上继续更新参数，把这些要求变成可计算的学习目标。先问数据提供了什么监督：给出正确回答，可以模仿；只告诉两个回答哪个更好，可以比较偏好；只有实际执行后的反馈，就需要收集行动及其结果。

SFT 是 Supervised Fine-Tuning（监督微调），DPO 是 Direct Preference Optimization（直接偏好优化），RL 是 Reinforcement Learning（强化学习）。LoRA 是 Low-Rank Adaptation（低秩适配），QLoRA 是在量化基座上训练 LoRA 的方法；adapter 在本章指附加的可训练参数。前面三者回答“学什么”，后面两者主要回答“用哪些参数学”。本文的概率均无物理单位，log 默认取自然对数；负对数损失可记为 nat，表示自然对数的信息量单位。

SFT、DPO、在线 RL 描述数据与目标如何构造；全参数微调、LoRA、QLoRA 描述更新哪些参数以及如何存储。SFT 可以使用 LoRA，在线 RL 也可以只更新 adapter，不能把它们当成互斥阶段。

| 配方 | 数据与目标 | 额外执行阶段 | 主要状态 |
|---|---|---|---|
| 自回归预训练 | 语料中的有效 next-token 预测 | 读取、采样、前后向与更新 | 模型、优化器、采样器 |
| SFT | 给定上下文与监督回答，按目标设置 mask | 通常离线数据供给，无须每步在线生成 | 模型、优化器、模板与数据版本 |
| LoRA 微调 | 目标可为 SFT、DPO 或 RL | 计算基座及低秩分支 | 冻结基座、adapter、adapter 优化器 |
| QLoRA 微调 | 冻结量化基座，训练低秩分支 | 解量化/融合计算、反向传播 | 量化基座及元数据、adapter 状态 |
| 标准离线 DPO | 同一 prompt 的 chosen/rejected 偏好对 | 策略与冻结 reference 的序列评分 | 配对身份、reference 版本、优化器 |
| 在线 PPO/GRPO 等 | 策略生成轨迹，再由反馈构造更新目标 | rollout、reward/环境、训练、换权 | 行为概率、组/轨迹、版本、队列 |

离线 DPO 不要求在每次训练更新中在线 rollout；数据集仍可能提前由生成系统产生。Reference 评分若预计算，必须与数据、tokenizer、mask 和 reference 参数版本绑定。不同偏好优化变体不一定采用标准 DPO 的全部职责。

<a id="s1-同样的序列训练目标怎样变化"></a>

### 同样的序列，训练目标怎样变化

设输入 `[BOS,p,a,EOS]`。独立序列的 next-token 目标可包含预测 `p,a,EOS`；若 SFT 将 `[BOS,p]` 作为 prompt，只训练回答，则保留预测 `a,EOS` 的 loss。Attention 仍让回答看到 prompt。

BOS/EOS 分别表示序列开始/结束标记，prompt 是已给定的输入条件。把这个例子展开到张量：批大小 $B=1$、输入长度 $T=4$、词表大小 $V=5$，token IDs 的形状为 `[1,4]`，模型 logits（尚未归一化的分数）形状为 `[1,4,5]`。取前三个 logits 位置，和标签 `[p,a,EOS]` 配对，得到 `[1,3]` 的目标 token 概率；最后一个输入位置后没有已知标签，因此不用它计算本例损失。

对位置 $t$、词表项 $v$，分数 $z_{t,v}$ 先经 softmax 变成概率，再按标签索引取出一项：

$$p_t(v)=\frac{e^{z_{t,v}}}{\sum_{u=1}^{V}e^{z_{t,u}}},\qquad
L=-\frac{\sum_t m_t\log p_t(y_t)}{\sum_t m_t}.$$

$y_t$ 是该 logits 位置应预测的 token，$m_t$ 是取 0 或 1 的训练 mask；分母是有效预测位置数，须大于零。教学假设三个目标的概率依次为 `[0.5,0.25,0.5]`，逐位置负对数为 `[0.693147,1.386294,0.693147]`。预训练 mask 为 `[1,1,1]`，均值约 0.924196 nat/token；回答 SFT mask 为 `[0,1,1]`，均值约 1.039721 nat/token。两个 loss 的分母和事件不同，不能直接比较大小来判断哪个模型更好。

这里采用 teacher forcing（教师强制）：预测 EOS 时输入前缀中放的是数据给定的 `a`，不会先随机生成一个 token 再接着训练。因此训练可以并行评分多个已知位置；在线生成则必须先确定上一个 token。这也解释了“训练一条回答”和“生成一条回答”为什么有不同的执行日程。

因此减少 loss 位置不直接消除 prompt 前向或全部反向成本；可训练参数仍可能依赖 prompt 的隐藏表示。计算节省要由实际 kernel、缓存或冻结路径验证。完整分母算例由[数据管线](<../04_Training/12_数据管线与训练循环.md#s2-packing的目标边界与有效分母>)维护。

<a id="s1-lora-减少哪些状态"></a>

### LoRA 减少哪些状态

对线性层 $W\in\mathbb R^{d_{out}\times d_{in}}$，令

$$y=Wx+(\alpha/r)BAx,$$

这里采用列向量输入，W 是已有的基座权重并保持冻结。新增的训练参数是 $A\in\mathbb R^{r\times d_{in}}$ 和 $B\in\mathbb R^{d_{out}\times r}$：先由 A 把输入投影到较小的 r 维空间，再由 B 映射回输出宽度，最后将这条分支加到原输出 Wx 上。系数 α/r 控制新增分支的尺度。

$d_{in},d_{out}$ 是输入与输出的特征数，$r$ 是选定的正整数中间宽度，限制 $BA$ 的秩最多为 $r$；$\alpha$ 是无量纲缩放超参数。它们都不是 GPU 数量。这里的权重和隐藏特征是模型的数值表示，没有秒或字节这样的物理单位；存储字节需要另乘 dtype 的宽度。

例如输入、输出宽度都为 4，取 r=1，则 A 是 1×4，先把四维输入变成一个数；B 是 4×1，再把这个数变成四维修正。A/B 合计 8 个参数，而完整 W 有 16 个；更大矩阵且 r 较小时，参数节省更明显。这也限制了新增矩阵 BA 的秩，不能将它看成任意完整矩阵更新。[LoRA 原论文](https://arxiv.org/abs/2106.09685)。

冻结 W 省去了 W 自己的梯度和优化器状态，却不一定省去整层反向。若前面还有可训练层，仍需把损失对输入 x 的影响传回去，基座分支也贡献 $W^T$ 乘以上游梯度。A/B 的梯度同样需要本次输入等中间值，所以可训练参数很少时，激活仍可能占据大量显存。

把线性层缩到能手算：取 $W=I_2$（二阶单位矩阵）、$x=[2,1]^T$、$A=[1,-1]$、$B=[1,2]^T$、$r=\alpha=1$。则 $Ax=1$、$BAx=[1,2]^T$，最终 $y=[3,3]^T$。若上游传回 $g=\partial L/\partial y=[1,-1]^T$，令 $c=\alpha/r$、$h=Ax$，链式法则给出

$$\frac{\partial L}{\partial B}=cgh^T,\qquad
\frac{\partial L}{\partial A}=c(B^Tg)x^T,\qquad
\frac{\partial L}{\partial x}=W^Tg+cA^TB^Tg.$$

三者形状依次为 `[d_out,r]`、`[r,d_in]`、`[d_in,1]`。本例得到 $\partial L/\partial B=[1,-1]^T$、$\partial L/\partial A=[-2,-1]$、$\partial L/\partial x=[0,0]^T$；最后的零来自两条路径恰好抵消，不能事先删去基座路径。训练时可保存或重算 $x,h$；对应反向使用完成后才能释放，A/B 梯度则保留到梯度累积和优化器更新完成。冻结 W 不是将整个层包在“不记录梯度”的区域里。

参数节省率来自直接计数：全矩阵有 $d_{out}d_{in}$ 项，分支有 $r(d_{in}+d_{out})$ 项；等宽 $d$ 时比率是 $2r/d$。所以 $r$ 接近 $d$ 时不再节省。低秩限制的是更新矩阵的表达空间，不保证所有任务都能在很小的 $r$ 下维持质量。基座与增量若在同一精度下可合并，部署可预先计算 $W+cBA$，省去在线分支；频繁切换 adapter 时则要权衡重合并成本与多分支计算。

教学例：$d_{in}=d_{out}=4096$、$r=16$ 时，基座有 16,777,216 个参数，A/B 合计 131,072，约为基座的 0.78125%。若仅为 adapter 配置 BF16 参数、FP32 梯度、FP32 主权重和两个 FP32 Adam 矩，每参数 18 字节，共 2.25 MiB；冻结 BF16 基座仍需 32 MiB。这里不计激活、工作区、分片和实现可能省去的副本。

BF16 是 16 位浮点存储，FP32 是 32 位浮点；上述 18 字节来自 $2+4+4+2\times4$。MiB 是 $2^{20}$ 字节，因而 $131072\times18/2^{20}=2.25$。这是明确状态配置下的账本，不是所有 LoRA 优化器的固定占用。

低秩参数少，不代表长序列激活或通信必然可忽略。目标层选择、rank、并行布局和优化器决定实际成本。

<a id="s1-qlora-与部署量化的接口"></a>

### QLoRA 与部署量化的接口

[QLoRA](https://arxiv.org/abs/2305.14314)在冻结的量化基座上把梯度传播到 LoRA，并提出 NF4、double quantization 与 paged optimizer 等设计。量化基座仍需要计算和表示元数据；不能把整个训练的计算精度称作“四位”。

为什么 LoRA 后还需要量化？上一例虽然几乎不为基座保存优化器状态，基座权重本身仍占 32 MiB。4 位编码的理想载荷是每参数半字节，同一矩阵只需 8 MiB；实际还要加分组尺度、码表及其他未量化层。NF4（4-bit NormalFloat）用适合近似正态权重的非均匀表示值；double quantization 再压缩量化尺度等常数；paged optimizer 借助分页管理优化器内存峰值，可能把压力转为主机内存和迁移等待。这三项节省的对象并不相同。

前向可以理解为 $\widehat W=\operatorname{dequantize}(Q,s)$，再计算 $\widehat Wx+cBAx$：$Q$ 保存低位编码，$s$ 是恢复尺度等元数据。内核可以分块解量化，不一定完整展开整份高精度权重。反向仍通过 $\widehat W$ 传递对输入的梯度，但不更新冻结的 $Q,s$；adapter 的计算精度、梯度精度和存储精度分别配置。节省常驻字节的代价包括解量化和可能的页面迁移，因此“更省显存”不能推出“每一步更快”。

导出时至少区分三种对象：独立 adapter、基座加 adapter、已合并后重新量化的模型。合并可表示为 $W'=W+(\alpha/r)BA$，但再量化的舍入使其不保证与在线 adapter 分支逐位等价。Artifact 应保存基座 revision、目标层、rank、缩放、tokenizer/template 与量化配置。不要将 MLA 架构参数 `q_lora_rank` 直接当作 adapter rank。

### 偏好对与在线轨迹有不同数据契约

标准 DPO 对同一 prompt 的回答 $y^+,y^-$ 使用

$$L=-\log\sigma\left(\beta\left[\log\frac{\pi_\theta(y^+|x)}{\pi_{ref}(y^+|x)}-\log\frac{\pi_\theta(y^-|x)}{\pi_{ref}(y^-|x)}\right]\right).$$

其中 x 是同一个问题，$y^+$ 是偏好数据中被选中的回答，$y^-$ 是被拒绝的回答；$\pi_\theta$ 是当前待训练策略，$\pi_{ref}$ 是固定参考策略。σ 是 sigmoid 函数，$\sigma(z)=1/(1+e^{-z})$，β 是控制该差值尺度的正系数。先分别计算两条回答相对参考策略的 logprob 变化，再用两者的差构造损失；第 2 节会用具体数字解释损失怎样下降。[DPO 原论文](https://arxiv.org/abs/2305.18290)。

一条回答的条件概率等于沿已知前缀的各 token 概率之积，因此它的 logprob 等于这些 token 的 logprob 之和。求和包含哪些位置，必须与 prompt、EOS 和截断规则一致。Chosen/rejected 即使分开放入不同 packed batch，也仍是一对有共同问题身份的数据；把两条同长度回答任意配成一对，会改变训练目标。

例如胜者两个目标 token 的当前概率为 `[0.5,0.4]`、参考概率为 `[0.25,0.4]`，序列概率分别为 0.2 和 0.1，故 $\Delta_+=\log2$。败者的当前概率 `[0.2,0.25]` 与参考 `[0.2,0.5]` 给出 0.05 和 0.1，故 $\Delta_-=-\log2$。取 $\beta=1$，偏好预测概率为 $\sigma(\log4)=0.8$，损失为 $-\log0.8\approx0.223144$ nat/偏好对。这是“胜过另一回答”的预测概率，不是胜者回答的序列概率 0.2。

批中有 $P$ 对、包含 prompt 的最大输入长度 $S$、最大回答目标长度 $T$ 时，可先把 $2P$ 条完整输入作为行评分。完整 logits 形状为 `[2P,S,V]`，抽取回答的预测位置并补齐后为 `[2P,T,V]`，按目标 ID 取 logprob 得到 `[2P,T]`，按 mask 求和得到 `[2P]`，最后按 pair ID 还原为 `[P,2]`。当前策略前向保留反向所需状态，参考前向不构造参数梯度；固定参考分数保存到 CPU 或离线缓存后，参考模型本次前向的临时状态即可回收。当前激活要等反向完成才能释放。配对表与实际 token 则需保留到该批消费和必要的复核结束。

在线 RL 则增加行为策略与反馈：一次生成何时完成、多个回答是否形成完整组、哪份权重生成了哪些动作，都会影响可消费性。执行图见[RL 全景](<25_RL目标与系统角色.md#s1>)。

### 怎样比较资源和质量

固定任务与评估，分别报告可训练参数、常驻状态、峰值激活、有效预测 token、前后向/评分/生成时间和总 GPU 时间。少更新参数、少做一个角色前向、减少无效 token，是不同来源的收益。

在相同数据上更快完成一步，不保证用更少成本达到相同质量。若改变目标、数据配比或 rank，应记录独立评估曲线；质量口径见[奖励与评估](<26_Rollout奖励与训练数据.md#s2>)。

## 2. 偏好损失下降，究竟说明什么

### 为什么会出现“相对参考策略的差”

先在固定问题 $x$、有限回答集合中推导，假设参考分布 $q(y)>0$，奖励分数 $R(y)$ 无物理单位。只最大化平均奖励容易把概率全部挤到最高分回答；加上 KL（Kullback–Leibler 散度）惩罚，控制偏离参考分布的成本：

$$\max_p\;\sum_y p(y)R(y)-\beta\sum_y p(y)\log\frac{p(y)}{q(y)},\qquad \sum_y p(y)=1.$$

$p$ 是待选的回答分布，$\beta>0$ 表示每单位 KL 的代价。用乘子 $\eta$ 加上约束 $\eta(\sum_y p(y)-1)$；对每个 $p(y)$ 求导并令零：

$$R(y)-\beta\left(\log\frac{p(y)}{q(y)}+1\right)+\eta=0
\quad\Longrightarrow\quad p^*(y)=\frac{q(y)e^{R(y)/\beta}}{Z},\qquad
Z=\sum_y q(y)e^{R(y)/\beta}.$$

中间一步是 $p(y)=q(y)e^{R(y)/\beta}e^{\eta/\beta-1}$。最后一项对所有回答相同，将所有 $p(y)$ 相加并令和为 1，就得到这项必须等于 $1/Z$；$Z$ 因而是归一化常数，不是要逐条标注的奖励。目标对 $p$ 是凹函数，所以在这里的正支持、有限集合条件下，这个驻点给出全局最优分布。

移项得到 $R(y)=\beta\log[p^*(y)/q(y)]+\beta\log Z$。再采用 Bradley–Terry 偏好模型，即胜者被选中的概率为 $\sigma(R(y^+)-R(y^-))$；两条回答属于同一问题，因此相减时 $\beta\log Z$ 消去。用参数模型 $\pi_\theta$ 表示这个最优分布，最小化观察到偏好标签的负对数概率，就得到第 1 节的 DPO 公式。关键前提是这种偏好模型与参考支持；有限数据、模型容量及优化误差仍会影响实际结果。[DPO 推导与假设](https://arxiv.org/html/2305.18290v3#S4)

在上述理想奖励优化中，较大的 $\beta$ 表示偏离参考更昂贵；在固定 logprob 差的 DPO 单样本公式里，它又直接缩放分类分数。两句话讨论的条件不同，不能从“梯度乘了 $\beta$”单独推断训练后的偏移大小。

### 从相对差到损失与梯度

一对回答一胜一负，很容易让人把 DPO 理解成“给胜者做 SFT，再惩罚败者”。区别在于，它比较的是两条回答**相对参考策略的概率变化**。先把上一节公式缩成一个可检查的量：

$$z=\beta\left[\Delta_+-\Delta_-\right],\qquad
\Delta_\pm=\log\pi_\theta(y^\pm\mid x)-\log\pi_{ref}(y^\pm\mid x),\qquad
L=\log(1+e^{-z}).$$

设教学输入为 $\Delta_+=2$、$\Delta_-=-1$、$\beta=0.1$，则 $z=0.3$、$L\approx0.554355$；策略与参考完全相同时，$z=0$、$L=\log2\approx0.693147$。导数 $\partial L/\partial z=-\sigma(-z)$ 表明优化会推动这个相对差增大。损失下降并不单独证明胜者的绝对概率上升：如果两条概率都下降、败者下降更多，相对差仍会变好。[DPO 原论文](https://arxiv.org/html/2305.18290v3#S4)给出了这一目标与偏好模型的关系。

展开求导：$d\log(1+e^{-z})/dz=-e^{-z}/(1+e^{-z})=-\sigma(-z)$，再乘 $\partial z/\partial\Delta_+=\beta$ 或 $\partial z/\partial\Delta_-=-\beta$。本例两条序列 logprob 的导数约为 −0.042556、+0.042556；继续通过模型反传才得到参数梯度，并非直接修改两个独立概率。一个反例是 $\Delta_+=-1,\Delta_-=-3,\beta=0.1$：两条概率都比参考低，损失仍从 0.693147 降到约 0.598139。偏好预测改善和绝对回答概率提高必须分别检验。

工程实现需要保住“同一对、同一条件、同一目标”：

| 容易省掉的细节 | 实际改变了什么 |
|---|---|
| 把回答 token 的 logprob 求和改成均值 | 不再是原来的序列概率比，长短回答的相对权重改变 |
| 胜负回答分别截断，却仍沿用全文偏好标签 | 模型训练的内容可能已不包含判定胜负的证据 |
| 参考分数预计算后更换模板或 EOS 规则 | 缓存不再对应同一事件，差值失去原有含义 |
| 分布式打散后仅凭相邻行配对 | 可能把不同问题的回答组成一对，shape 仍然合法 |

冻结的参考策略提供了缓存机会：固定数据和评分条件时，可提前计算参考分数，减少训练期间的模型驻留与前向。缓存身份至少关联参考权重、精度与评分实现、实际 token、mask 和序列求和规则；改变其中一项，就要重新判断能否复用。先对少量样本核对在线与缓存评分，再比较节省的时间和存储成本。

偏好损失与导数可用[标准库复算程序](<../examples/rl_infra_contracts.py>)检查，验证范围限于上述教学模型。

## 本章回顾

预训练、SFT、参数高效微调和偏好优化改变目标与可训练状态。训练循环的共同语义仍然成立，但激活保存、数据构造和额外评分模型的需求需要重新核算。

**检查理解：** 冻结基座后，哪些训练状态消失，哪些激活仍要保存？离线偏好数据与在线 RL 有何区别？
