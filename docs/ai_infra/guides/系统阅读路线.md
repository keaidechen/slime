# 从一次计算到完整系统：26 篇阅读主线

这条主线建立共同语言，不要求先读完所有基础专题。每一阶段都沿前一阶段留下的问题前进；特殊模型、八类并行的其他分支和框架源码放在相应专题中深入。

只需要能读基本 Python 和矩阵乘法记号；公式中的符号、形状与假设在正文解释。数字电路、Linux 环境等可从[专题导航](专题导航.md)补读。
