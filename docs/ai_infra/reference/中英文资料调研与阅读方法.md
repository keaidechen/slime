# 并行训练的中英文资料：怎样把动机、实现和结果讲完整

调研日期：2026-10-03。以下比较针对实际查阅的页面，不把一篇文章的特点泛化为整个社区。外部资料用于学习组织方式；本仓库的实现解释以 `Megatron-LM` commit `21fe0fe1597932421f1bb0efd93f469376a7a255` 为准。

## 1. 范围与分类

本专题覆盖 DP、ZeRO/FSDP、TP、PP、SP、CP、EP，并把 **ETP（Expert Tensor Parallelism）独立展开**。这是八个学习主题，不是八个可直接相乘的设备轴：FSDP 是状态分片策略，Megatron SP 复用 TP 组，ETP 是 expert 层使用的 TP。

不同教材会把 SP/CP 合并，把 ZeRO 放进 DP，或把 ETP 放进 MoE。因此“5D / 7 种 / 8 类”本身不能说明覆盖程度。检查的是：参数、token、梯度分别由谁持有，布局如何改变，通信与优化器更新能否闭合。

## 4. 对“出发点、怎么做、最终结果、副作用”的回答

| 写作维度 | 调研观察 | 本仓库采用的写法 |
|---|---|---|
| 出发点 | Playbook 从容量/计算/通信矛盾推进；中文教程常从模型扩展问题起步 | 每章先写 baseline 的具体瓶颈，区分参数、activation、优化器和吞吐 |
| 怎么做 | 原理图、时序、配置和代码常分布在不同层次 | 全局数学 → 每 rank 所有权 → 前向 → 反向 → optimizer，附源码符号 |
| 最终结果 | 有的页面给能力描述，有的给运行 loss，有的给性能曲线 | 分开写数学等价、理论资源变化、实际测量；没有实测就不给加速数字 |
| 副作用 | 常散落于 performance、limitations、注意事项 | 明列额外通信、临时显存、颗粒度、负载不均和可能改变训练语义的选项 |
| 组合 | 系统指南重视 topology/folding；入门教程多讲单一策略 | dense/expert 两张网格，说明 SP/FSDP 的位置，避免机械乘法 |
| 验证 | 好教程同时提供运行入口与预期结果 | 小数值参考 → 真实多卡一步等价 → 稳态性能，分别说明证据范围 |

## 5. 本专题的统一阅读结构

每类并行都用以下问题读，答案可能分布在原理篇与实现篇，索引见[并行切分总览](<../04_Training/14_数据并行与状态分片.md>)：

1. **出发点**：不使用它时，具体什么放不下或什么在等待？
2. **切分与所有权**：切哪个 tensor 轴？谁保存完整/局部参数、激活、梯度和状态？
3. **怎么执行**：一步前向、反向、通信和更新按什么顺序发生？
4. **等价性**：哪里是 SUM，哪里是平均？mask、位置和 token 顺序怎样保持？
5. **结果**：减少的是哪一项内存/工作？可否用形状或字节数核对？
6. **代价**：增加多少通信阶段、临时 buffer 或等待？哪些负载下会更慢？
7. **实现与组合**：配置最终到哪个类/函数？依赖 TP/CP/EP/ETP/EDP 的哪个组？
8. **验证**：基线、观测点、预期结果、失败现象和证据局限是什么？

这八问是此次针对本仓库归纳的写作方法，并非声称上面每份资料都采用同一模板。

## 6. 本次落地范围

- 统一入口纳入八类，保留现有数值推演，给已有 DP/TP/PP/FSDP 章节增加执行与验收说明。
