# 维护规则与证据范围

本系列只有一处正文目录和一个[总入口](../README.md)。原理文章负责定义、推导与成本，源码文章解释固定实现，论文文章保留原始问题与实验条件；比较其他方法时用短回顾与链接连接，不复制整章。

## 内容取舍

保留能解释机制的公式、完整算例、执行顺序、失败条件和一手来源。重复定义、连续多次总结、已完成的计划、旧路径兼容页和逐章节迁移台账不再维护。历史方法仍用于解释设计演进；日期较早本身不是删除理由。

产品支持矩阵、路线图与“最新版本”容易失效。正文优先写稳定的设计边界，支持状态指向发布说明；引用性能数字时保留模型、硬件、工作负载和版本条件。数学推导、CPU 示例、源码检查与 GPU 实测分别说明，不以链接通过或代码能解析代替事实核验。

既有走读的主要固定基线为 Megatron-LM `21fe0fe1597932421f1bb0efd93f469376a7a255`、SGLang `f5155d960286db25952217f343ee0d3c358f7f77`、FlashAttention `e9cf2c1651d2303191eb40a739a3c135fda00999`。具体章节的版本说明优先；这些标识不意味着它们是上游最新版本。

[贯穿案例源码证据](贯穿案例源码证据.json)保留 24 个文件与符号的历史哈希。其主仓库 HEAD 与当前工作区 HEAD 不同，本次对照的文件和符号记录仍相同；该差异不通过覆盖旧快照消除。新实现判断应检查实际分支。

[数学参考](../examples/README.md)覆盖小矩阵、归约、有限差分和教学状态机。它们不执行真实 NCCL/TE 后端，也不证明整个框架的容错或训练质量。旧稿中的模型、硬件和性能材料没有在目录整理时被全部重新核验。

## 链接与维护

新增正文加入所属专题目录，保持从总入口可到达。链接用相对路径，源码以路径与符号名定位；保留仍被仓库内引用的章节锚点。目录整理后的旧 URL 不继续提供跳转文件，仓库内引用随正文更新。

`python3 tools/validate_learning_docs.py` 直接检查当前目录的本地链接、锚点、标题、代码围栏、阅读可达性与 Python 示例语法，不再依赖多份目录清单。源码证据脚本使用 Python 3.10+。
