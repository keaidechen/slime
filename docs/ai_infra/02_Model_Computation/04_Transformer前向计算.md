## 1. Transformer 与 Attention：从 token 到一层完整计算

上一章解释了数组的形状和存储。本节把数组接成一个能根据前文预测后续 token 的模型。先看前向计算，即“给定输入和当前参数，计算输出”；下一章再解释参数怎样学习。数值表示沿用上一章的约定。

<a id="s1-输入与参数分别是什么"></a>

### 输入与参数分别是什么

Tokenizer（分词／编码器）把文本映射为词表中的 token ID。词表是模型可识别的离散单位集合，ID 是编号，不表示大小关系。Embedding（嵌入）是一张可学习的表，每个 ID 对应一行向量。

例如 `[2,5]` 两个 ID 查表后得到两个四维向量，形状为 `[2,4]`。一次处理 B 条样本、每条 S 个位置、每位置 H 个特征时，整体形状为 `[B,S,H]`，记作 $X\in\mathbb R^{B\times S\times H}$。ℝ 表示实数；hidden size 是特征宽度 H，hidden state 是随输入变化的中间表示。参数是查找表和后续矩阵中的可学习数值，同一组参数可以处理很多次不同输入。

Attention 混合不同位置的信息；FFN（Feed-Forward Network，前馈网络）分别变换每个位置的特征。多层模型反复执行这两类计算，位置数通常不变，向量内容逐渐改变。

<a id="s1-qkv-与可见性"></a>

### Q、K、V 与可见性

先只看一条序列。输入 X 分别乘三个参数矩阵，得到 Q=XWq、K=XWk、V=XWv，这种线性变换也叫投影。Q（Query，查询）表示当前位置用什么特征寻找信息；K（Key，键）用来和查询比较；V（Value，值）是被混合的信息。它们都是向量，不是数据库里的字符串键值。

一套这样的投影称为一个 head（注意力头）。设查询位置有 S_q 个、可访问位置有 S_k 个，Q/K 的向量宽度为 d、V 的宽度为 d_v，则：

$$Q\in\mathbb R^{S_q\times d},\quad K\in\mathbb R^{S_k\times d},\quad V\in\mathbb R^{S_k\times d_v},$$
$$P=\operatorname{softmax}(QK^T/\sqrt d+M),\qquad O=PV.$$

上标 T 表示转置。QKᵀ 的形状为 `[S_q,S_k]`，每个元素比较一个查询和一个键；除以 √d 用于调节分数尺度。直觉是：若 Q、K 的各分量相互独立、均值为零且方差为 1，那么 d 项乘积之和的方差为 d，标准差为 √d；除以 √d 后可把这个尺度保持在 1 附近，避免仅因向量变宽就让 softmax 过度集中。这是简化的初始化直觉，不是对训练中所有 Q/K 分布的保证。

Softmax 将每行分数 z 转为非负、和为 1 的权重：$p_j=\exp(z_j)/\sum_k\exp(z_k)$。exp(z) 表示 $e^z$，e≈2.718；先取指数使数值为正，再除以总和。输入分数常称 logits；此处是注意力分数，还不是输出词表的预测分数。O 的每一行是按 P 加权求和的 Value，形状为 `[S_q,d_v]`。

M 是 mask（访问限制）。假设训练输入是 `[我,喜欢,猫]`，第一个位置只能看“我”，第二个能看“我、喜欢”。这种 causal（因果）限制防止预测下一个 token 时偷看答案。在加法 mask 公式里，允许项加 0、禁止项加负无穷，使后者的 softmax 权重为 0。短序列补齐到共同长度称为 padding，补齐位置应按规则排除；独立样本合装称为 packing，还需隔离跨样本访问。

一个可以手算的例子：Q=[1,0]，两个 Key 为 [1,0]、[0,1]，Value 为 [2,0]、[0,4]。缩放后的分数约为 [0.707,0]，指数化后约为 [2.028,1]，归一化得到 [0.670,0.330]。加权输出约为 [1.340,1.321]。若第二个位置被禁止访问，权重变为 [1,0]，输出就是 [2,0]。

<a id="s1-多头与-kv-表达"></a>

### 多头与 KV 表达

多头让多套投影同时参与信息混合，通常再拼接各头输出并做一次输出投影。例如两个头各为每个位置产生一个 2 维输出，拼接后得到 4 维向量，再乘输出矩阵回到模型的特征宽度。各头可以学到不同的查询和匹配方式；“多头”并不表示把同一份注意力结果简单复制多次。MHA（Multi-Head Attention，多头注意力）为各 query head 配备相应 K/V；MQA（Multi-Query Attention，多查询注意力）让多个 query heads 共享一组 K/V；GQA（Grouped-Query Attention，分组查询注意力）在若干 query heads 间共享 K/V。它们改变参数化，不能在任意已训练模型上随意切换而假设质量不变。

生成新 token 时，过去位置的 K/V 在适用条件下可以保留复用，这份历史状态称为 KV Cache。先记住缓存的对象，第 19–20 章会完整解释写入、复用和释放。标准 KV 纯负载可按 $2LTn_{kv}db$ 核算：L 为层数，T 为所有请求驻留位置总数，n_kv 为 KV 头数，d 为每头宽度，b 为每元素字节数；2 来自 K、V 两份。T 已汇总 batch，不再额外乘 B。

更深入的 MLA（Multi-head Latent Attention，多头潜在注意力）压缩历史表示；稀疏 Attention 只访问选中的历史位置；线性／递推结构改变状态组织。这些是后续设计分支，可在[Attention 设计空间](<06_模型结构与执行成本.md#s2>)补读，不是理解当前计算的前提。

<a id="s1-ffn归一化与残差"></a>

### FFN、归一化与残差

普通 FFN 可写为 $\phi(XW_1)W_2$。W₁ 把特征宽度从 H 扩到 F，φ 是逐元素非线性函数，W₂ 再把宽度变回 H。例如 H=4、F=8，每个位置经历 4→8→4 的变换，不同位置使用同一组参数。可以把 φ 暂取为 ReLU：正数保持不变，负数变成零。它使输出不能再简化为一个固定矩阵乘；若去掉 φ，两次线性变换可以合并为 $X(W_1W_2)$，增加中间宽度也没有引入这种非线性表达。

门控 FFN 则从输入得到两条变换后的向量，用其中一条逐元素调节另一条，例如将某些分量放大、减小或压到零，再做输出投影。MoE（Mixture of Experts，混合专家）准备多个这样的子网络，由路由器为每个 token 选择其中几个。两者分别改变子网络内部的计算与子网络的选择；主线先按普通 FFN 理解，下一章以后再展开这些设计。

一个示意 block（重复堆叠的层结构）为：

$$U=X+\operatorname{Attention}(\operatorname{Norm}(X)),$$
$$Y=U+\operatorname{FFN}(\operatorname{Norm}(U)).$$

残差就是这里的加法：把子层结果加回输入。例如某个位置的输入为 `[1,2]`，子层输出为 `[0.1,-0.2]`，相加后是 `[1.1,1.8]`。子层学习的是在已有表示上增加怎样的变化；当子层输出为零时，输入仍可以原样向后传递，因此两个被加的张量需要形状相容。

Norm（归一化）则先调整一个位置内部特征的数值尺度。以 RMSNorm 为例，先求各分量平方的平均，再开平方得到均方根，用它缩放原向量，并配合可学习的缩放参数。暂忽略稳定项和可学习参数，向量 `[3,4]` 的均方根为 $\sqrt{(9+16)/2}\approx3.536$，缩放后约为 `[0.849,1.131]`。LayerNorm 还会先减去特征均值。上面的公式将 Norm 放在子层之前，这个顺序叫 Pre-Norm；它怎样影响深层网络的梯度，见[残差基础](<../appendices/models/residual/残差与归一化基础.md>)。

位置编码使模型获得顺序信息。RoPE（Rotary Position Embedding，旋转位置编码）根据位置旋转特定 Q/K 分量，不等同于简单加一个位置向量。首次阅读只需知道位置还需要进入计算，无需先掌握旋转推导。

<a id="s1-训练prefilldecode"></a>

### 训练、Prefill、Decode

一层 Attention 的 O 不是最终文字。经过多层 block 后，词表投影把每个位置的 H 维向量变成 $V_{vocab}$ 个词表分数，$V_{vocab}$ 为词表大小（与 Attention 中的 Value 矩阵 V 区分）；对这些 logits 做 softmax，才得到下一个 token 的预测概率。

训练时，已知文本 `[我,喜欢,猫]` 可以用前两个位置分别预测“喜欢”和“猫”。正确目标概率若为 0.25，交叉熵损失为 −ln(0.25)≈1.386；ln 是自然对数，目标概率越高，损失越小。多个有效位置的损失按规定汇总，下一章解释怎样利用它改变参数；负 logprob 与交叉熵的关系、logsumexp 的推导及稳定计算见[从目标 token 到交叉熵与 logsumexp](<05_损失自动微分与优化器.md#s1-从目标token到交叉熵与logsumexp>)。

生成时没有预先给出的“猫”，模型要根据预测分布选出 token，将其接回输入后才能继续，这种逐步依赖叫自回归。本节采用这种只根据已知前文生成的 decoder-only 结构；decoder 是解码器，此处不需要另一套独立 encoder（编码器）提供输入表示。

Prefill（前缀填充）一次处理已知前缀，得到历史 K/V 和首个待生成 token 的分数；decode（逐步解码）消费新 token、计算其 K/V，并复用历史。训练虽也做因果预测，却已知完整训练文本，所以多个位置的前向可以一起算。

Prefill 常有更多矩阵并行工作，decode 常包含较多历史读取；实际是计算受限（算术能力限制速度）还是带宽受限（搬运能力限制速度），还取决于形状、batch 和硬件，第 7 章再解释。

### 沿三个 token 对齐训练与生成

设输入问题只有 token A，模型生成 B、C，暂不考虑终止 token。重新计算这条回答的概率时，可以一次输入 `[A,B,C]`，但需要读取的概率位置是：

| 前向位置 | 该位置可见的输入 | 此处词表分布预测谁 | 本例应取的值 |
|---|---|---|---|
| 0 | A | 第一个回答 token | $\log p(B\mid A)$ |
| 1 | A、B | 第二个回答 token | $\log p(C\mid A,B)$ |
| 2 | A、B、C | 后续 token | 没有对应目标，排除 |

BOS（Begin Of Sequence）与 EOS（End Of Sequence）分别是编码规则中的序列起始、结束标记；是否插入以及对应 ID 要由 tokenizer 和模板约定。Logprob 是概率的自然对数，例如 p=0.25 时 logprob≈−1.386；一条序列的条件概率连乘可以在对数域写成各位置 logprob 相加。

这就是预测位置比目标 token 的输入位置早一位的原因。B 出现在输入中，是为了预测 C；B 自己的概率必须从前一个位置取。把 `logits[:,t]` 与 `tokens[:,t]` 直接对应，会让模型在已经看到答案后给答案打分。若训练目标还包含 EOS，则补上该目标，并使用位置 2 的分布预测它。

这类使用已知历史目标的前向称为 teacher forcing。它能并行重算已生成动作的条件概率，但不能提前生成尚未知晓的动作。在相同权重、位置、可见性和确定性执行条件下，逐步带 KV 的执行与完整因果前向应描述相同条件分布；具体内核与精度仍可能造成数值差异。

因此第一次连接训练框架与推理引擎时，先固定上述三个 token，逐位置比较概率，再测试自由生成。还需固定 tokenizer、对话模板、BOS/EOS、position ID 和采样变换。自由生成一旦在某步选中不同 token，后续上下文也不同，就无法再把后续概率差简单归因于某个算子。

<a id="s1-演进的核心问题"></a>

### 演进的核心问题

现在可以沿一条路径走通：token ID → embedding → 多层 Attention/FFN → 词表 logits → 预测概率。训练额外比较正确目标得到 loss，生成则选取 token 继续执行。模型越大、序列越长，计算、存储和数据移动会以不同方式增长。

自检：注意力 P 和词表预测概率相同吗？不同。前者决定从哪些位置混合信息，后者决定下一个 token 的分布。两者都可能使用 softmax，但对象和形状不同。

## 本章回顾

一层 Transformer 通过投影、Attention、FFN、残差与归一化变换表示。训练可以对已知位置并行计算预测，生成则受新 token 的因果依赖约束。
