# 性能与可靠性：从执行依赖到可成立的结论

局部算子快，不代表整步快；传输完成，也不代表状态已经一致。这个专题把成本、观测、关键路径和恢复放在同一条执行链上解释。

## 先读四篇，建立分析方法

[性能语言与成本模型](00_concepts.md) → [证据与因果](证据与因果.md) → [六种性能现象](07_causal_analysis.md) → [故障模型与恢复](故障模型与恢复.md)。先确定目标和依赖，再判断证据支持什么，最后理解状态被中断后如何恢复。
