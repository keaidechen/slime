# AI Infra：从模型计算到训练、推理与 RL 系统

## 前言

本书研究模型如何被训练出来、如何提供推理服务，以及如何通过生成与反馈继续学习。全书先建立模型计算和硬件执行的共同基础，再依次展开训练、推理与 RL 系统，最后通过性能分析和完整案例讨论系统设计。

读者只需能阅读基本 Python，并了解矩阵乘法记号。张量布局、梯度、GPU 执行和分布式状态会在正文中逐步解释；公式说明符号与假设，算例在文中展开，完成阅读不以安装框架或运行 GPU 实验为前提。

## 全书结构

全书分为七篇、32 章，下面的目录也是唯一的连续阅读顺序。每章末尾连接下一章。各章开头说明本章的问题，章内目录组织推导与算例，结尾提供回顾与检查理解的问题。

第一篇建立三类系统的全景和共同设计语言；第二、三篇解释模型工作以及设备如何执行。第四篇沿完整训练作业展开，第五篇沿在线推理服务展开，第六篇连接后训练和 RL 闭环。第七篇通过训练、推理和 RL 三个综合案例把机制、实现与验证联系起来。

正文中的附录链接供查询特殊结构、论文或固定源码，不是继续阅读的前置任务。附录不另设学习路线；阅读正文时可以直接前往下一章。
