# 06_reference资料

本目录用于查询正文之外的推导、实现和历史资料；全书的连续阅读顺序见[总目录](<../../../../README.md>)。

参考篇有三种不同用途：覆盖矩阵告诉你到哪里找答案以及版本边界；术语表帮助把缩写翻译成张量和动作；源码问题把跨章节的依赖串起来。第一次阅读不必先背术语，可以在具体公式或调用链遇到陌生词时回查。

建议带着一个明确问题查阅，例如“为什么 loss 一致而梯度小了一倍”。先用术语表确认 SUM/AVG 与 microbatch 的含义，再到源码问题检查目标分母和通信域，最后回到固定版本代码核对实现。官方页面的功能介绍、数学推演与目标环境的实测日志是不同类型的证据。
