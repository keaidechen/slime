# 05_design_and_failures资料

本目录用于查询正文之外的推导、实现和历史资料；全书的连续阅读顺序见[总目录](<../../../../README.md>)。

这一组把前面的机制转成可证伪的判断：慢在数据、计算还是通信；省掉的是常驻状态还是峰值；loss 相同是否足以证明一步更新相同。先学指标与时间线，再按一个小配置算清拓扑、batch 和内存，最后区分数学参考、真实运行和性能测量。

遇到问题时先记录输入、预期和实际差异，再提出一个能通过改变单个条件检验的解释。例如“RS 太晚开始，因为 bucket 太大”应预测缩小桶后通信开始提前；若开始时间没变，就要检查 hook 或配置是否进入该路径，而不是继续盲调带宽参数。
