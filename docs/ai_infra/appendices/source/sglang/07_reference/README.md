# 07_reference资料

本目录用于查询正文之外的推导、实现和历史资料；全书的连续阅读顺序见[总目录](<../../../../README.md>)。

参考页用于带着具体疑问回查：覆盖索引帮助找到同版本的文档与源码，术语表帮助判断一个词属于请求、设备、缓存还是采样层。它们不代替前面的逐步算例。

例如遇到“decode 变慢”，先确认它指语言模型增量生成、token 转文本，还是 VAE 媒体解码；遇到“支持某模型”，再核对具体任务、硬件、精度及优化组合。范围明确后，才能选对源码入口。
