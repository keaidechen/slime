# Muon：矩阵更新、Newton–Schulz 与分布式边界

> 前置：[SGD、Momentum 与 AdamW](<../../02_Model_Computation/05_损失自动微分与优化器.md#s2>)、[矩阵形状与布局](<../../02_Model_Computation/03_张量形状与数值表示.md#s1>)。本篇把理想极分解、有限迭代近似、工程配方分别定义；数值均为教学构造。

## 从逐元素尺度到矩阵方向

设线性权重 $W\in\mathbb R^{m\times n}$，梯度为 G。Adam 按各元素的历史 m/v 更新；矩阵方法还利用一整块更新的行列关系。Muon 先形成动量，再用 Newton–Schulz 类迭代变换矩阵的奇异值。[作者的设计说明](https://kellerjordan.github.io/posts/muon/)给出了这一构造。

本篇选定一个无 Nesterov 的教学配方，$B_0=0$：

$$B_t=\beta B_{t-1}+(1-\beta)G_t,\qquad
O_t=\operatorname{NS}_K(B_t),\qquad
W_t=(1-\eta_t\lambda)W_{t-1}-\eta_t s(m,n)O_t.$$

K 为迭代次数，$s(m,n)$ 为声明的形状缩放。其他实现可能用未归一化动量、Nesterov 混合或不同缩放。理想正尺度不变性不能保证有限精度、epsilon 和有限迭代下所有写法都逐位等价；实际调用须固定整个配方。

## 理想目标：保留方向，改变奇异值

先假设 B 满秩，薄 SVD 为 $B=U\Sigma V^T$，秩 $r=\min(m,n)$。理想极因子为 $Q=UV^T$，把非零奇异值替换为 1：

- $m\ge n$ 时，$Q^TQ=I_n$，列正交。
- $m\le n$ 时，$QQ^T=I_m$，行正交。

矩形矩阵通常不能同时满足两式。若秩亏，规范的部分极因子 $U_rV_r^T$ 保留零奇异方向；全零输入的多项式迭代仍为零。不能宣称任意输入都会变成满秩正交矩阵。这里正交化的是**更新**，更新后的 W 本身不一定正交。

独立例子：

$$G=\begin{bmatrix}2&1\\1&2\end{bmatrix}
=U\operatorname{diag}(3,1)U^T,\qquad
U=\frac1{\sqrt2}\begin{bmatrix}1&1\\1&-1\end{bmatrix}.$$

G 为对称正定矩阵，所以理想 Q 为单位矩阵。初始动量为零、不加 decay、忽略 epsilon，比较首步的未乘学习率方向：

| 方法 | 方向 | 本例揭示什么 |
|---|---|---|
| SGD | $[[2,1],[1,2]]$ | 保留原梯度元素幅度 |
| Adam，偏差校正首步 | $[[1,1],[1,1]]$ | 各元素均为正；该方向矩阵反而秩一 |
| 理想 Muon，$s=1$ | $[[1,0],[0,1]]$ | 按奇异方向处理，结果不同于元素取符号 |

这个比较只隔离几何差别；相同学习率并不构成公平的质量或速度比较。

## 先用三次迭代看清计算过程

取非零输入 $X_0=B/\|B\|_F$，先用便于推导的三次 Newton–Schulz：

$$X_{k+1}=\frac32X_k-\frac12(X_kX_k^T)X_k.$$

若 $X_k=U\operatorname{diag}(x_i)V^T$，每个奇异值独立变成 $f(x)=1.5x-0.5x^3$。对本例 $0<x\le1$ 的范围，迭代趋近 1，零仍为零。本节三次式用于教学，不能当作下节五次实现的逐位参考。

上例 $\|G\|_F=\sqrt{10}$，所以 $X_0=[[0.632456,0.316228],[0.316228,0.632456]]$，奇异值为 $3/\sqrt{10}$ 和 $1/\sqrt{10}$。第一轮 Gram 矩阵为 $X_0X_0^T=[[0.5,0.4],[0.4,0.5]]$，代回可得下面第一轮输出。

| 迭代 k | 两个奇异值 | $X_k$ 的对角元素 | 两个非对角元素 |
|---|---|---:|---:|
| 0 | 0.948683、0.316228 | 0.632456 | 0.316228 |
| 1 | 0.996117、0.458530 | 0.727324 | 0.268794 |
| 2 | 0.999977、0.639592 | 0.819785 | 0.180193 |
| 3 | 1.000000、0.828567 | 0.914283 | 0.085717 |
| 5 | 1.000000、0.997444 | 0.998722 | 0.001278 |
| 极限 | 1、1 | 1 | 0 |

设 $W_0=I$、$\eta=0.1$、$s=1$、$\lambda=0$。三次式五轮后更新为近似 $[[0.900128,-0.000128],[-0.000128,0.900128]]$；使用理想 Q 则恰为 $0.9I$。方向接近不代表有限迭代已经精确正交。

## 五次近似与缩放也是算法定义

常用五次形式为

$$A_k=X_kX_k^T,\qquad
X_{k+1}=aX_k+bA_kX_k+cA_k^2X_k.$$

一组历史系数为 $(3.4445,-4.7750,2.0315)$，对应奇异值映射 $f(x)=ax+bx^3+cx^5$。仅代入 $x=1$ 就得 $f(1)=0.701$，因此这组系数不是让所有奇异值严格收敛到 1 的迭代；有限步的近似目标与三次教学式不同。系数序列、迭代次数、归一化 epsilon、计算 dtype、是否转置都会影响结果。[PyTorch Muon 的版本化定义](https://docs.pytorch.org/docs/2.14/generated/torch.optim.Muon.html)可用于对照另一份具体配方。

形状缩放也需要显式记录。由满秩理想 Q 的 $\|Q\|_F^2=r$，可直接推出

$$\operatorname{RMS}(Q)=\sqrt{r/(mn)}=1/\sqrt{\max(m,n)}.$$

若希望理想更新 RMS 为给定 $\rho$，则乘 $\rho\sqrt{\max(m,n)}$；实际 NS 输出不精确等于 Q 时还会有误差。其他 spectral/shape 缩放有不同约定。扩展到 LLM 的研究强调衰减和更新尺度的重要性，具体实验条件见[Muon is Scalable for LLM Training](https://arxiv.org/abs/2502.16982)。不能从同名 Muon 推出同一个有效步长。

## 参数分组决定哪块矩阵被正交化

常见做法将 hidden matrix 交给 Muon，而 embedding、输出层、bias 和 norm 等交给另一优化器。具体分组不是单凭 `ndim == 2` 就能决定；例如 embedding 也是二维矩阵。源码可能使用属性标签并允许覆盖规则。

融合 QKV 权重可以整体正交化，也可以先按 Q/K/V 的逻辑边界拆分，分别更新后拼回。这会改变 Gram 矩阵和缩放形状；还须处理 GQA 的头数、交错存储和 gate 等额外分量。不能按“前三等份”猜边界。MoE 的多个专家也不应仅因打包在同一个 buffer 就被当成同一逻辑矩阵。

这些选择影响训练算法和 checkpoint 身份。具体标签与 QKV 还原见[Megatron 优化器走读](<../source/megatron/03_state_and_memory/04_adam_muon_execution.md>)。MuonClip 等模型稳定性规则另由[模型案例](<../models/architecture_cases/数值优化器与预测.md#read-66>)维护。

## 分片反例：完整矩阵与各行独立更新不同

把上面的 G 按行切给两个 TP rank。若各自把 $[2,1]$ 和 $[1,2]$ 作为独立的 $1\times2$ 矩阵，其精确行极因子拼接后为

$$Q_{local}=\frac1{\sqrt5}\begin{bmatrix}2&1\\1&2\end{bmatrix},\qquad
Q_{local}Q_{local}^T=\begin{bmatrix}1&0.8\\0.8&1\end{bmatrix}\ne I.$$

完整矩阵 Q 为 I。即便每个 rank 的局部正交化都精确，拼接结果也不等价。Blockwise 可以是有意选择的算法，但需要按这个定义评价质量。

| 方案 | 数据与计算责任 | 额外代价 |
|---|---|---|
| Local/blockwise | 各 TP 分片作为独立矩阵 | 语义改变，缩放基于局部形状 |
| Gather 后完整计算 | 获取完整逻辑矩阵，计算后切回 | 全矩阵通信、临时容量；可能重复计算 |
| 分布式矩阵迭代 | 通过 collective 补全范数、Gram 或矩阵乘依赖 | 多轮通信与同步，依切分维度决定 |

例如按列分片 $X=[X_0,X_1]$，有 $XX^T=X_0X_0^T+X_1X_1^T$，可归约局部 Gram 后更新各列。归一化也需要全局平方和；只归约 Gram 却各自归一化仍非同一算法。按行分片可以选择另一侧 Gram 或不同分布式乘法，成本随矩阵形状变化。

DP 的状态 owner 与 TP 的矩阵切分是两件事。按完整参数矩阵分配 DP owner，可以避免把一个矩阵的状态任意切成元素段；owner 拿到的参数仍可能是 TP shard。梯度规约、正交化、更新后参数同步必须分别闭合，不能用一次“all-gather”概括全部路径。

## 常驻状态少了，峰值与更新时间仍需核算

标准 Muon 的矩阵组通常保存一份动量，AdamW 保存 m/v；混合优化器的其他组仍有自己的状态。NS 需要 X、Gram 和实现工作区，也可能需要完整矩阵 gather。

教学账本：4096×4096 矩阵的每份 FP32 状态为 64 MiB，两份 Adam 矩为 128 MiB，一份 FP32 Muon 动量为 64 MiB。但仅一份额外 FP32 同尺寸 Gram 就再占 64 MiB，且还有输入、输出或乘法临时量；持久状态减少 64 MiB 不等于峰值必减 64 MiB。

设转置后 $m\le n$。按上面的直接五次实现，每轮三个矩阵乘法约为 $4m^2n+2m^3$ FLOPs（乘加计 2）；K 轮乘 K。融合、Gram 复用和分布式算法可以改变账本。MoE 的每个专家形状和实际参与优化的矩阵数也要计入，不能只统计本批前向激活的专家数。

## 用相同质量目标比较完整成本

设独立教学假设：AdamW 达标需要 20T token，某 Muon 配方需要 16T；若每 token 墙钟成本却为原来的 1.3 倍，总时间比为 $16/20\times1.3=1.04$，反而增加 4%。若固定设备数与其他成本，成本倍率低于 1.25 才能在这个例子中缩短总时间。该例没有借用任何模型实测收益。

实际比较固定模型、数据和质量门槛，并分别调优合理的学习率/衰减等配方；报告训练曲线、达标 token、墙钟时间、GPU-hours、优化器关键路径和峰值内存。矩阵切分、精度或 NS 系数变化后，先检查一次更新，再检查长期质量。
